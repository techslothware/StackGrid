# 0011. REST externally, gRPC internally

- **Status:** Accepted
- **Date:** 2026-10-02

## Context

Phase 2 needs an API style for vendors, webhooks, a future web UI, and a future agent.

## Decision

Expose REST + JSON, defined OpenAPI-first, with Go stubs generated by `oapi-codegen`. Long operations return `202 Accepted` + job ID, with status polling, an SSE event stream, and signed outgoing webhooks. Use gRPC only for the future pull agent.

## Consequences

- Easy to integrate for vendors and third parties.
- The OpenAPI spec also generates the web UI client.
